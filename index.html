AJUDA - PAINEL DO GABINETEOrientações de uso e cuidados operacionais

Como usar

O painel consulta o banco de dados automaticamente. A bolinha verde indica conexão normal e a contagem mostra o tempo até a próxima leitura.

Clique nos números dos indicadores para visualizar quais municípios compõem cada total. Em Mapa de Impactos, clique nos pontos para consultar os detalhes de cada município e utilize os filtros inferiores.

Atualização dos dados

Para a operação remota, mantenha a planilha com a mesma estrutura de colunas. Alterações válidas são refletidas automaticamente no painel.

O que não fazer

Não renomeie as abas ou colunas da planilha, não apague Latitude/Longitude, não altere a URL de conexão sem necessidade, não exclua os arquivos das pastas static e data e não edite manualmente os arquivos do sistema durante a operação.

Relatório

Use IMPRIMIR / PDF para abrir o relatório corporativo. Na janela de impressão, selecione Salvar como PDF. O relatório inclui indicadores, municípios, ocorrências e mapa.
